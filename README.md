# 💼 Jobify

A modern full-stack job application tracker built with **Next.js 14**, **TypeScript**, **Prisma**, **Clerk Authentication**, and **React Query**. Jobify helps users organize their job search by managing applications, tracking progress, and visualizing application statistics through an intuitive dashboard.

## ✨ Features

- 🔐 Secure authentication with Clerk
- 💼 Create, edit, and delete job applications
- 📋 Track application status (Pending, Interview, Offer, Declined)
- 📊 Interactive analytics dashboard
- 📈 Application charts with Recharts
- 🔍 Search and filter jobs
- 📱 Responsive design
- 🌙 Light & Dark mode
- ⚡ Server Actions
- 🗄️ PostgreSQL database with Prisma ORM
- ✅ Form validation using React Hook Form & Zod
- 🚀 Optimistic data fetching with React Query
